## `> ground_stations`

Everything is named after a moon. It keeps the map readable.

| Node | Role | Stack |
|:--|:--|:--|
| 🛰️ **titan** | Primary compute | Proxmox on Minisforum MS-A2 · Docker Compose via Arcane GitOps |
| 🌘 **triton** | Edge / controller | VPS · self-hosted NetBird mesh controller |
| 🌑 **io** | Storage | UGREEN NAS · TrueNAS CE · RAIDZ1 |
| 🌕 **ganymede** | Inference | Mac mini M4 · Ollama host for local models |

**Backbone:** Traefik (Cloudflare DNS-01) · Pi-hole split-horizon DNS · 1Password service accounts for per-server secret scoping · NetBird for east-west segmentation.
